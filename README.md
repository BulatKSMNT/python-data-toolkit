# Основы Data Science, Data Engineering
## 📌 О репозитории
В этом репозитории собрано портфолио из 9 модулей, сфокусированных на **базовых и продвинутых навыках Data Science, Data Analytics и Machine Learning**. 

Проекты демонстрируют уверенное владение полным жизненным циклом данных: от парсинга сырой информации через API и UNIX-утилиты до построения ООП-пайплайнов, оптимизации потребления памяти в Pandas, написания сложных SQL-запросов для A/B-тестирования и поиска бизнес-инсайтов с помощью интерактивных визуализаций.

Особый акцент сделан на **production-ready** практиках: следование стандартам PEP8, работа с виртуальными окружениями (`venv`), профилирование кода (`cProfile`, `timeit`), оптимизация памяти (через генераторы), логирование и написание unit-тестов (`pytest` с мокированием).

---

## Технологический стек
* **Data Engineering и сбор данных:** Bash, AWK, `BeautifulSoup`, `requests`, обработка JSON/CSV/TSV.
* **Манипуляция данными и оптимизация:** Продвинутый `pandas` (даункастинг типов, категориальные переменные, векторизация), `numpy`.
* **Базы данных и SQL:** SQLite, сложные JOIN-ы, подзапросы, агрегации, аналитика в БД.
* **Визуализация данных:** `matplotlib`, `seaborn`, `plotly` (интерактивные анимации).
* **Разработка (Software Engineering):** Архитектура ООП, `logging`, `pytest`, `cProfile`, `psutil`.

## Модули проектов

### 1. [Обработка данных в командной строке UNIX](./01_unix_tools)
* **Цель:** Обработка сырых JSON-данных из API прямо в терминале.
* **Ключевые навыки:** Настроил пайплайн для получения данных (API HeadHunter), фильтрации, парсинга и разбиения вакансий на CSV-файлы, используя исключительно Bash, `curl`, `jq` и `awk`.

### 2. [Базовый Python и структуры данных](./02_python_core)
* **Цель:** Глубокое понимание структур данных и базовых алгоритмов.
* **Ключевые навыки:** Реализовал шифрование текста (шифр Цезаря), конвертацию форматов файлов и сложные операции со словарями и множествами для сегментации клиентов в маркетинговой аналитике.

### 3. [ООП и архитектура приложений](./03_oop_architecture)
* **Цель:** Переход от плоских скриптов к объектно-ориентированному программированию.
* **Ключевые навыки:** Спроектировал многоклассовую систему для расчета распределения вероятностей, интегрировал её с `logging`, конфигурационными файлами (`config.py`) и вебхуками Telegram API для автоматической отправки отчетов.

### 4. [Окружения, Web Scraping и тестирование](./04_env_and_testing)
* **Цель:** Воспроизводимость среды, сбор данных из сети и тестирование кода.
* **Ключевые навыки:** Написал скрапер финансовых данных с Yahoo Finance. Провел профилирование кода с помощью `cProfile` и `pstats` для поиска узких мест (bottlenecks). Покрыл скрапер unit-тестами с использованием `pytest` и замокал (mock) HTTP-запросы.

### 5. [Эффективный код и управление памятью](./05_optimization)
* **Цель:** Написание высокопроизводительного Python-кода для больших датасетов.
* **Ключевые навыки:** Обработал датасет MovieLens размером >600МБ, используя **Генераторы (`yield`)** для минимизации потребления RAM. Сравнил скорость выполнения циклов с `map`/`filter`/`reduce` и `collections.Counter` с помощью встроенного модуля `timeit`.

### 6. [Разведочный анализ данных (EDA) MovieLens](./06_movielens_eda)
* **Цель:** End-to-end аналитика и Data Storytelling.
* **Ключевые навыки:** Разработал продвинутый ООП-интерфейс для анализа датасета MovieLens. Обогатил данные, спарсив IMDb на лету (режиссеры, бюджеты, сборы). Подготовил подробный аналитический отчет в Jupyter Notebook с выводами о поведении пользователей, спорных фильмах и жанровых трендах.

### 7. [Продвинутая работа с Pandas](./07_pandas_advanced)
* **Цель:** Глубокое понимание Pandas для сложного препроцессинга.
* **Ключевые навыки:** Очистил датасет автомобильных штрафов (imputations через `ffill` и средние значения), применил сложные группировки и сводные таблицы. **Снизил потребление памяти DataFrame более чем на 60%** за счет даункастинга типов (`float64` -> `float32`, `int64` -> `int8`) и использования категорий.

### 8. [SQL и A/B-тестирование](./08_sql_and_ab_testing)
* **Цель:** Запросы к реляционным базам данных и проверка гипотез.
* **Ключевые навыки:** Спроектировал витрины данных (Data Marts), объединив таблицы `pageviews` и `commits` через `sqlite3`. Рассчитал дельты времени для оценки результатов A/B-теста (Treatment vs. Control), проанализировав влияние новой функции платформы на успеваемость студентов.

### 9. [Визуализация данных и Storytelling](./09_data_visualization)
* **Цель:** Коммуникация бизнес-инсайтов через визуализацию.
* **Ключевые навыки:** Построил статистические графики (Boxplots, Scatter Matrices, Heatmaps), используя `matplotlib` и `seaborn`. Создал интерактивные анимированные чарты с помощью `plotly` для визуализации временной динамики активности пользователей.
